# بات سالن زیبایی (تلگرام)

## امکانات
- ارسال خودکار لیست قیمت (دکمه، دستور `/prices`، یا وقتی مشتری کلمه «قیمت/تعرفه/هزینه» بنویسد)
- رزرو نوبت: انتخاب خدمت ← روز ← ساعت خالی ← شماره تماس
- جلوگیری از تداخل نوبت‌ها بر اساس مدت هر خدمت
- مشاهده و لغو نوبت توسط مشتری
- اطلاع‌رسانی نوبت جدید/لغو به مدیر
- یادآوری خودکار چند ساعت قبل از نوبت
- مدیر: `/today` نوبت‌های امروز، `/broadcast` ارسال لیست قیمت به همه مشتریان

## راه‌اندازی
1. در تلگرام از `@BotFather` بات بسازید و توکن بگیرید.
2. `.env.example` را به `.env` کپی و پر کنید.
3. قیمت‌ها و ساعت کاری را در `config.py` ویرایش کنید.
4. اجرا:
```
pip install -r requirements.txt
python bot.py
```

## واتساپ / اینستاگرام
این دو API رسمی تجاری (Meta) لازم دارند. منطق رزرو در `bot.py` قابل انتقال است؛ فقط لایه پیام‌رسان عوض می‌شود.
